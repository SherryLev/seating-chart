# Seatwell

A visual event seating planner built with React, TypeScript, and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Use the editor

- Paste guest names one per line in the guest list.
- Choose a table shape and seat capacity, then add it to the floor plan.
- Click a guest and an open seat, or drag a guest directly onto a seat.
- Rename, reshape, resize, or remove guests and tables.
- Charts save automatically in this browser. Use Import and Export to move a chart as JSON.
- Print creates a simplified floor-plan view.

The first version is browser-only: it does not use accounts, a hosted database, or online sharing.

## Checks
